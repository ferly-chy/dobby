## Dobby-Fork Android

Dobby 是一个轻量级、模块化的利用钩子框架，现在已针对 Android 进行现代化改造和专门优化。

### 核心特性
- **Android 专用：** 针对 Android 生态系统进行了精简和优化。
- **多架构支持：** 完整支持 ARM, ARM64, X86, 和 X86-64。
- **现代化 C++：** 使用最新的 C++ 标准（C++23/26）构建。
- **轻量且模块化：** 极小的开销，采用基于插件的架构。
